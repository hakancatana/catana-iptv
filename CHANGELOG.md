# Changelog

## 1.6.0
- **M3U playlists** as a second profile type next to Xtream Codes
- **Multi-View**: watch 2 or 4 channels at once
- **TV / remote mode**: larger interface, full screen, arrow-key navigation everywhere
- **Backup**: export and import profiles, favourites, history and settings
- **Report a problem**: prepares a GitHub issue with app details and logs, credentials hidden
- TV guide: titles of running programmes stay readable next to the channel column
- End-to-end tests run on every change

## 1.5.0
- Linux packages: `.deb` (Ubuntu, Linux Mint, Debian), `.rpm` (Fedora), AppImage
- Password encryption with the Linux keyring

## 1.4.0
- Update check on start-up; Windows downloads and installs the update
- Mini player (picture-in-picture)
- Movie cards show the release year
- Releases are built by GitHub Actions

## 1.3.1
- Posters and thumbnails keep their aspect ratio inside equal-sized cards
- Fixes for series pages opened from the home slider

## 1.3.0
- New name: Catana IPTV
- 9 languages
- Redesigned movie and series pages
- macOS builds

## 1.2.0
- Home screen with slider, movie detail pages, global search
- Full TV guide
- My Account: account details, category manager, parental PIN, device check
- Encrypted password storage, previous channel (Backspace), screen stays awake

## 1.1.0
- Rewind live TV up to 30 minutes, LIVE button
- Channel panel with categories inside the player
- Refresh button

## 1.0.0
- First version: Xtream Codes login, live TV, movies, series, player with settings
